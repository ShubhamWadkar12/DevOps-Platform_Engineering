# 🏗️ Software Development Models

> **Goal:** Understand the different software development models, their advantages, disadvantages, and why Agile became the preferred approach for modern software development.

---

# 📖 Overview

A software development model is a structured approach that defines how software is planned, developed, tested, and delivered.

Over the years, different models have been introduced to solve different types of problems. Choosing the right model depends on the project's requirements, complexity, timeline, and customer involvement.

Understanding these models helps you appreciate why Agile and DevOps became the industry standard.

---

After completing this topic, you will be able to:

* Learn the most common development models.

# 📌 What is a Software Development Model?

A software development model is a framework that defines the sequence of activities involved in developing software.

It helps teams organize their work, reduce risks, improve collaboration, and deliver better software.

Software Development Models are methodologies used to implement the SDLC.

---

# 1️⃣ Waterfall Model

The Waterfall Model is the oldest and simplest software development model.

Each phase is completed before moving to the next one.

```text
Requirements
      ↓
Design
      ↓
Development
      ↓
Testing
      ↓
Deployment
      ↓
Maintenance
```

### Advantages

* Simple and easy to understand.
* Well-structured process.
* Suitable for small projects with fixed requirements.

### Disadvantages

* Difficult to handle changing requirements.
* Customer feedback comes late.
* Testing starts only after development is complete.
* Slow delivery.

---

# 2️⃣ V-Model

The V-Model is an extension of the Waterfall Model where every development phase has a corresponding testing phase.

```text
Requirements      ↔ Acceptance Testing
Design            ↔ System Testing
Architecture      ↔ Integration Testing
Development       ↔ Unit Testing
```

### Advantages

* Better quality through early testing.
* Easy to manage.
* Suitable for projects requiring high reliability.

### Disadvantages

* Less flexible.
* Expensive to make changes later.
* Not ideal for rapidly changing requirements.

---

# 3️⃣ Spiral Model

The Spiral Model focuses on continuous risk analysis and repeated development cycles.

Each cycle includes planning, development, testing, and risk evaluation.

### Advantages

* Good for large and complex projects.
* Handles risks effectively.
* Supports changing requirements.

### Disadvantages

* Expensive.
* Complex to manage.
* Requires experienced teams.

---

# 4️⃣ Agile Model

Agile is an iterative and incremental software development approach.

Instead of delivering the entire application at once, Agile delivers small working features in short development cycles called **Sprints**.

```text
Plan
  ↓
Develop
  ↓
Test
  ↓
Review
  ↓
Repeat
```

### Advantages

* Faster delivery.
* Continuous customer feedback.
* Flexible and adaptable.
* Better collaboration.
* Higher customer satisfaction.

### Disadvantages

* Requires active customer involvement.
* Scope can change frequently.
* Needs good communication within the team.

---

# 📊 Comparison of Development Models

| Feature           | Waterfall      | V-Model          | Spiral         | Agile                       |
| ----------------- | -------------- | ---------------- | -------------- | --------------------------- |
| Flexibility       | Low            | Low              | Medium         | High                        |
| Customer Feedback | Late           | Late             | Regular        | Continuous                  |
| Risk Handling     | Low            | Medium           | High           | Medium                      |
| Testing           | At the end     | Throughout       | Every cycle    | Every sprint                |
| Best For          | Small Projects | Critical Systems | Large Projects | Modern Software Development |

# 🌍 Real-World Example

Imagine you're developing an **Online Shopping Application**.

* **Waterfall:** Build the entire application before showing it to users.
* **V-Model:** Test every development stage to ensure quality.
* **Spiral:** Build the application in phases while analyzing risks.
* **Agile:** Deliver features like login, product catalog, cart, and payment in separate sprints.

Today, most software companies prefer **Agile** because it enables faster delivery, frequent feedback, and continuous improvement.

---

# 💡 Why Agile Became Popular

Traditional models worked well when requirements rarely changed.

Modern businesses, however, need to:

* Release features quickly.
* Adapt to changing customer needs.
* Fix issues faster.
* Deliver updates regularly.

Agile makes all of this possible, which is why it has become the most widely adopted development methodology.

# 💼 Interview Questions


- **What is a software development model?**  
  A software development model is a structured approach used to plan, build, test, and deliver software.

- **What is the Waterfall Model?**  
  The Waterfall Model is a linear approach where each phase is completed before moving to the next.

- **What is the V-Model?**  
  The V-Model is an SDLC model where every development phase has a corresponding testing phase.

- **What is the Spiral Model?**  
  The Spiral Model is a risk-driven model that combines planning, development, testing, and risk analysis in repeated cycles.

- **What is Agile?**  
  Agile is an iterative development approach that delivers software in small, frequent releases with continuous feedback.

- **Why is Agile preferred over Waterfall?**  
  Agile is preferred because it is more flexible, allows frequent changes, and delivers software faster.

- **Which development model is most commonly used today?**  
  Agile is the most widely used software development model today.

# 💼 DevOps Fundamentals Interview Questions


This chapter contains the most commonly asked interview questions from the DevOps Fundamentals section of this roadmap.

It is designed as a quick revision guide for students and beginners before they move on to Linux and other technical topics.

---

# 🎯 Learning Objectives

After completing this topic, you will be able to:

* Revise important DevOps concepts.
* Prepare for beginner-level interviews.
* Strengthen your understanding of Agile, Scrum, Jira, and DevOps.
* Build confidence before learning advanced DevOps tools.

---

# 📌 Software Development

* **What is Software Development?**                         
  Software development is the process of designing, building, testing, deploying, and maintaining software.

* **What are the main phases of software development?**                                 
  Requirement Gathering, Planning, Design, Development, Testing, Deployment, and Maintenance.

* **Who are the common members of a software development team?**                                 
  Product Owner, Business Analyst, UI/UX Designer, Developers, QA Engineers, DevOps Engineers, and Operations Team.

---

# 📌 SDLC

* **What is SDLC?**                               
  SDLC (Software Development Life Cycle) is a structured process for developing high-quality software.

* **What are the stages of SDLC?**                             
  Requirement, Planning, Design, Development, Testing, Deployment, and Maintenance.

* **Why is SDLC important?**                                  
  It provides a structured approach to developing software efficiently and with better quality.

---

# 📌 Software Development Models

* **What is a Software Development Model?**                                
  It is a framework that defines how software is planned, developed, tested, and delivered.

* **Name some Software Development Models.**                             
  Waterfall, V-Model, Spiral, and Agile.

* **Which model is most commonly used today?**                                          
  Agile.

---

# 📌 Agile

* **What is Agile?**                                 
  Agile is a software development methodology that delivers software in small, frequent releases while encouraging collaboration and customer feedback.

* **Why was Agile introduced?**                                        
  Agile was introduced to overcome the limitations of traditional development models like Waterfall.

* **What are the four values of the Agile Manifesto?**                                        
  Individuals and interactions, Working software, Customer collaboration, and Responding to change.

---

# 📌 Scrum

* **What is Scrum?**                                 
  Scrum is an Agile framework used to manage software development through short iterations called Sprints.

* **What is a Sprint?**                                
  A Sprint is a fixed period, usually 1–4 weeks, during which a team completes planned work.

* **What are the three Scrum roles?**                              
  Product Owner, Scrum Master, and Development Team.
                            
* **What is the Product Backlog?**                             
  A prioritized list of all work required for the product.
                       
* **What is the Sprint Backlog?**                                          
  A list of Product Backlog items selected for the current Sprint.

---

# 📌 Jira

* **What is Jira?**                   
  Jira is a project management and issue-tracking tool developed by Atlassian.

* **Why is Jira used?**                              
  It is used to manage projects, track tasks, report bugs, and support Agile workflows.

* **What is an Epic?**                       
  An Epic is a large feature that is divided into multiple smaller stories or tasks.

* **What is a User Story?**                              
  A User Story describes a feature from the user's perspective.

* **What is a Bug?**                          
  A Bug is a defect or problem in the software.

---

# 📌 DevOps

* **What is DevOps?**                
  DevOps is a culture and set of practices that improves collaboration between development and operations teams.

* **Why was DevOps introduced?**                                  
  DevOps was introduced to reduce communication gaps, automate processes, and speed up software delivery.

* **Is DevOps a tool or a culture?**                               
  DevOps is primarily a culture supported by practices and tools.

* **What are the key principles of DevOps?**                                  
  Collaboration, Automation, Continuous Integration, Continuous Delivery, Monitoring, and Feedback.

---

# 📌 CALMS

* **What does CALMS stand for?**                           
  Culture, Automation, Lean, Measurement, and Sharing.

* **Why is the CALMS Framework important?**                                 
  It provides the principles needed to build a successful DevOps culture.

---

# 📌 DevOps Lifecycle

* **What is the DevOps Lifecycle?**                               
  It is a continuous process of planning, developing, building, testing, releasing, deploying, operating, monitoring, and improving software.

* **Why is Monitoring important?**                                     
  Monitoring helps detect issues, track performance, and maintain system reliability.

---

# 📌 CI/CD

* **What is CI/CD?**                               
  CI/CD is a DevOps practice that automates software building, testing, and deployment.

* **What is the difference between Continuous Delivery and Continuous Deployment?**                                              
  Continuous Delivery requires manual approval before production, while Continuous Deployment deploys automatically after successful tests.

---

# 📌 Modern DevOps

* **What is Modern DevOps?**                            
  Modern DevOps combines cloud computing, automation, security, observability, and AI to improve software delivery.

* **What is GitOps?**                           
  GitOps uses Git as the single source of truth for infrastructure and deployments.
                   
* **What is DevSecOps?**                             
  DevSecOps integrates security throughout the DevOps lifecycle.

* **What is Platform Engineering?**                                     
  Platform Engineering focuses on building internal platforms that improve the developer experience.

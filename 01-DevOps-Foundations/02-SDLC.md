# 🔄 Software Development Life Cycle (SDLC)

> **Goal:** Understand the step-by-step process of building, testing, deploying, and maintaining software from an idea to a real-world application.

---

# 📖 Overview

Every successful software application follows a structured process before it reaches users. This process is called the **Software Development Life Cycle (SDLC)**.

The SDLC provides a systematic approach to planning, designing, developing, testing, deploying, and maintaining software. It helps teams deliver high-quality software on time while reducing risks, improving collaboration, and ensuring customer requirements are met.

# 📌 What is SDLC?

The **Software Development Life Cycle (SDLC)** is a structured process used to develop software from the initial idea to deployment and maintenance.

It ensures that software is built in an organized, efficient, and predictable manner while maintaining quality throughout the development process.

---

# 🔄 Phases of SDLC

```text
Requirement Gathering
        ↓
Planning
        ↓
System Design
        ↓
Development
        ↓
Testing
        ↓
Deployment
        ↓
Maintenance
```

---

# 1️⃣ Requirement Gathering

This is the first phase of SDLC.

The development team works with stakeholders and customers to understand what the software should do.

### Activities

* Understand business requirements
* Identify user needs
* Define project scope
* Gather functional and non-functional requirements

### Output

* Software Requirement Specification (SRS)

---

# 2️⃣ Planning

After gathering requirements, the team creates a project plan.

### Activities

* Estimate cost
* Estimate timeline
* Allocate resources
* Identify risks
* Create project schedule

### Output

* Project Plan

---

# 3️⃣ System Design

The design phase defines how the software will be built.

### Activities

* Design application architecture
* Design database
* Create UI/UX designs
* Define APIs
* Select technologies

### Output

* System Design Document

---

# 4️⃣ Development

Developers start writing the source code based on the approved design.

### Activities

* Write code
* Review code
* Use version control (Git)
* Build application features

### Output

* Working Software

---

# 5️⃣ Testing

The application is tested to identify and fix bugs before release.

### Activities

* Functional Testing
* Integration Testing
* System Testing
* Performance Testing
* Security Testing
* User Acceptance Testing (UAT)

### Output

* Tested Software

---

# 6️⃣ Deployment

After successful testing, the software is released to users.

### Activities

* Deploy application
* Configure servers
* Release new version
* Monitor deployment

### Output

* Live Application

---

# 7️⃣ Maintenance

Software continues to evolve after deployment.

### Activities

* Fix bugs
* Release updates
* Improve performance
* Add new features
* Apply security patches

### Output

* Stable and Updated Software

---

# 🌍 Real-World Example

Imagine a company wants to build an **Online Food Delivery App**.

| SDLC Phase            | Example                                              |
| --------------------- | ---------------------------------------------------- |
| Requirement Gathering | Customers want to order food online.                 |
| Planning              | Team estimates budget and timeline.                  |
| Design                | UI screens, database, and architecture are designed. |
| Development           | Developers build the application.                    |
| Testing               | QA tests ordering, payments, and login.              |
| Deployment            | Application is released to users.                    |
| Maintenance           | Bugs are fixed and new features are added.           |

# ✅ Advantages of SDLC

* Clear development process
* Better project planning
* Improved software quality
* Reduced development risks
* Easier maintenance
* Better collaboration
* Higher customer satisfaction

---

# ⚠️ Limitations of Traditional SDLC

Traditional SDLC works well, but it has some challenges:

* Development can be slow.
* Feedback is often received late.
* Testing usually happens after development.
* Deployments may require significant manual effort.
* Development and Operations teams may work separately.

These challenges led to the adoption of **Agile** and later **DevOps**, which help teams deliver software faster and more reliably.

# 💼 Interview Questions


- **What is SDLC?**  
  SDLC (Software Development Life Cycle) is a step-by-step process used to develop high-quality software.

- **Why is SDLC important?**  
  It helps deliver software efficiently with better quality, lower cost, and fewer errors.

- **What are the phases of SDLC?**  
  Planning → Requirement Analysis → Design → Development → Testing → Deployment → Maintenance.

- **Which phase comes after planning?**  
  Requirement Analysis comes after the planning phase.

- **What happens during the testing phase?**  
  The software is tested to find and fix bugs before it is released.

- **What is the purpose of the maintenance phase?**  
  To fix bugs, improve performance, and update the software after deployment.

- **How does DevOps improve the traditional SDLC?**  
  DevOps automates development and deployment, making software delivery faster, more reliable, and continuous.

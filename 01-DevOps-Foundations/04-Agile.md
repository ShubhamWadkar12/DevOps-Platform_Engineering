# 🚀 Agile Methodology

As software projects became larger and customer requirements started changing more frequently, traditional development models like Waterfall became less effective.

To solve these challenges, the software industry adopted **Agile**, a flexible and iterative approach to software development that focuses on collaboration, customer feedback, and continuous improvement.

Today, Agile is one of the most widely used methodologies in software development and forms the foundation of modern DevOps practices.

# 📌 What is Agile?

**Agile** is a software development methodology that focuses on delivering software in **small, incremental releases** instead of building the entire application at once.

Rather than spending months developing everything before receiving feedback, Agile teams work in short development cycles called **Sprints**, allowing them to deliver working software frequently and respond quickly to changing requirements.

---

# ❓ Why Was Agile Introduced?

Traditional development models had several challenges:

* Requirements often changed during development.
* Customer feedback was received very late.
* Bugs were discovered near the end of the project.
* Delivering software took a long time.
* Making changes was expensive.

Agile was introduced to make software development more flexible, collaborative, and customer-focused.

---

# 📜 Agile Manifesto

The Agile Manifesto is based on four core values:

* **Individuals and interactions** over processes and tools.
* **Working software** over comprehensive documentation.
* **Customer collaboration** over contract negotiation.
* **Responding to change** over following a fixed plan.

These values encourage teams to focus on delivering value rather than simply following rigid processes.

---

# ⭐ Agile Principles

Some important Agile principles include:

* Deliver working software frequently.
* Welcome changing requirements.
* Collaborate closely with customers.
* Build projects around motivated individuals.
* Keep development simple whenever possible.
* Continuously improve through regular feedback.

---

# 🔄 How Agile Works

Agile development is an iterative cycle where teams continuously plan, build, test, review, and improve software.

```text
Plan
   ↓
Develop
   ↓
Test
   ↓
Review
   ↓
Release
   ↓
Feedback
   ↓
Repeat
```

Each cycle delivers a small but functional part of the application.

---

# 📊 Agile vs Waterfall

| Feature             | Waterfall         | Agile                  |
| ------------------- | ----------------- | ---------------------- |
| Development         | Sequential        | Iterative              |
| Customer Feedback   | End of project    | Continuous             |
| Requirement Changes | Difficult         | Easy                   |
| Software Delivery   | Once              | Frequent               |
| Testing             | After development | Throughout development |
| Flexibility         | Low               | High                   |

---

# 🌍 Real-World Example

Imagine you're building an **Online Shopping Application**.

### Waterfall Approach

The team builds the complete application before releasing it to users.

### Agile Approach

The team releases features in small increments:

* Sprint 1 → User Login
* Sprint 2 → Product Catalog
* Sprint 3 → Shopping Cart
* Sprint 4 → Payment Gateway
* Sprint 5 → Order Tracking

Customers can start using the application early, provide feedback, and help improve future releases.

---

# ✅ Advantages of Agile

* Faster software delivery.
* Better customer satisfaction.
* Continuous feedback.
* Easier to handle changing requirements.
* Improved collaboration.
* Better software quality.
* Reduced project risks.

---

# ⚠️ Limitations of Agile

* Requires active customer involvement.
* Frequent changes can affect planning.
* Teams need strong communication.
* Less suitable for projects with fixed requirements and strict regulations.

# 💼 Interview Questions

- **What is Agile?**  
  Agile is a software development approach that delivers software in small, frequent releases with continuous feedback.

- **Why was Agile introduced?**  
  Agile was introduced to make software development faster, more flexible, and better at handling changing requirements.

- **What are the four values of the Agile Manifesto?**  
  - Individuals and interactions over processes and tools.  
  - Working software over comprehensive documentation.  
  - Customer collaboration over contract negotiation.  
  - Responding to change over following a plan.

- **What are the benefits of Agile?**  
  Agile provides faster delivery, better quality, flexibility, continuous feedback, and improved customer satisfaction.

- **How is Agile different from Waterfall?**  
  Agile is flexible and iterative, while Waterfall follows a fixed, step-by-step process.

- **Why is customer feedback important in Agile?**  
  Customer feedback helps improve the product and ensures it meets user needs.

- **What is meant by iterative development?**  
  Iterative development means building and improving software in small, repeated cycles.

# 📌 Learning Principles

* Learn **Why** before **How**.
* Practice every topic with hands-on labs.
* Build at least one mini project for each phase.
* Document everything in GitHub.
* Focus on production-ready skills.
* Understand troubleshooting instead of memorizing commands.
* Learn continuously and revise regularly.

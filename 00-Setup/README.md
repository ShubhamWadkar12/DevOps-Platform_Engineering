# Development Environment Setup

## Overview

Before practising DevOps, it is important to create a professional development environment.

This setup will be used throughout the entire DevOps and Platform Engineering journey.

Instead of installing tools randomly, we will build a stable, reusable environment similar to what professional engineers use.

---

## Objectives

- Install Linux using WSL2
- Configure Windows Terminal
- Install VS Code
- Configure Git & GitHub
- Generate SSH Keys
- Organize Workspace
- Install Useful Extensions
- Verify Everything Works

---

## Tools Covered

- Windows Terminal
- WSL2
- Ubuntu
- VS Code
- Git
- GitHub
- SSH
- Markdown

---

## Expected Outcome

After completing this section, the development environment will be fully configured and ready for learning Linux, Git, Docker, Kubernetes, AWS, Terraform, and other DevOps tools.

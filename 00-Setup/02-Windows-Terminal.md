# Windows Terminal

Windows Terminal is a modern terminal application developed by Microsoft that allows you to access multiple command-line tools from a single interface.

It supports:
- Command Prompt (CMD)
- PowerShell
- WSL (Ubuntu)
- Azure Cloud Shell

For DevOps, **Ubuntu (WSL)** will be our primary terminal.

---

# Why Windows Terminal?

- Multiple tabs and panes
- Better performance than Command Prompt
- Customizable appearance
- Supports multiple shells
- Integrated with WSL2
- Keyboard shortcuts for faster workflow

---

# Interview Questions

- **What is Windows Terminal?**
  > Windows Terminal is a modern terminal application that supports multiple command-line tools and shells in one window.
- **How is Windows Terminal different from Command Prompt?**
  > Windows Terminal is a terminal host that can run multiple shells with tabs and customization, while Command Prompt is a single command-line shell.
- **Why do DevOps engineers prefer Windows Terminal?**
  > It allows working with PowerShell, Command Prompt, WSL, Azure Cloud Shell, and other terminals simultaneously in a single interface.
- **Which shells are supported by Windows Terminal?**
  > Windows Terminal supports Command Prompt (CMD), PowerShell, WSL (Ubuntu, Debian, etc.), Azure Cloud Shell, Git Bash, and other compatible shells.

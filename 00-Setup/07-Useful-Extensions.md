# Useful VS Code Extensions

VS Code extensions enhance the editor by adding features that improve productivity, code quality, and the overall development experience. The following extensions are recommended for DevOps, Cloud, and Platform Engineering.

---

# Recommended Extensions

| Extension                           | Purpose                                                              |
| ----------------------------------- | -------------------------------------------------------------------- |
| **Remote - WSL**                    | Develop directly inside the WSL Linux environment.                   |
| **GitLens**                         | View Git history, commits, and code changes.                         |
| **Docker**                          | Manage Docker containers and images from VS Code.                    |
| **Kubernetes**                      | Work with Kubernetes clusters and YAML files.                        |
| **Python**                          | Python language support, debugging, and IntelliSense.                |
| **YAML**                            | Syntax highlighting, validation, and auto-completion for YAML files. |
| **Terraform**                       | Syntax support and validation for Terraform files.                   |
| **Markdown All in One**             | Improve Markdown editing and formatting.                             |
| **Better Comments**                 | Create clear and organized code comments.                            |
| **Error Lens**                      | Display errors and warnings directly in the editor.                  |
| **GitHub Pull Requests and Issues** | Review pull requests and manage GitHub issues.                       |

---

# Best Practices

* Install only the extensions that are needed.
* Keep extensions updated.
* Disable unused extensions to improve performance.
* Use the **Remote - WSL** extension when working with Linux projects.

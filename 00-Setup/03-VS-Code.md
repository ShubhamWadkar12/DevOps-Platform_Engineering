# Visual Studio Code (VS Code)
Visual Studio Code (VS Code) is a free, lightweight, and powerful code editor developed by Microsoft. It is one of the most popular editors for DevOps, Cloud, and Software Development.

---

# Why VS Code?

- Lightweight and fast
- Built-in Terminal
- Git & GitHub integration
- Large Extensions Marketplace
- Supports multiple programming languages
- Works seamlessly with WSL2

---

# Features

- IntelliSense (Code Completion)
- Integrated Terminal
- Debugging
- Extensions
- Git Integration
- Remote Development

# Best Practices

- Use VS Code with WSL2.
- Keep extensions updated.
- Open projects directly from the Linux filesystem.
- Use the integrated terminal for development.

---
## Connect WSL with VS Code Using Terminal

### Step 1: Open Terminal and type
```bash
wsl
```

### Step 2: Go to your project folder
```bash
cd /path/to/your/project
```

**Example:**
```bash
cd ~/DevOps
```
or
```bash
cd /mnt/c/Users/Shubh/DevOps
```

### Step 3: Open the folder in VS Code
```bash
code .                        ( code -> opens vs code ;  . -> opens the current folder)
```

# Interview Questios

Q: What is VS Code?            
A: VS Code is a free, lightweight, and powerful code editor developed by Microsoft.

Q: Why is VS Code popular among DevOps engineers?                
A: It supports coding, debugging, Git integration, extensions, and remote development in one place.

Q: What is the Remote - WSL extension?                  
A: It lets you open and work on Linux files inside WSL directly from VS Code.

Q: Name some useful VS Code extensions for DevOps.                      
A: Docker, Kubernetes, Remote - WSL, GitLens, YAML, Terraform, Python, and Azure Tools.

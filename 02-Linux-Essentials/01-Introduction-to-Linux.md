# 📌 What is Linux?

Linux is a **free**, **open source**, **Unix like operating system kernel** created by **Linus Torvalds** in **1991**.

The Linux kernel manages the communication between software and computer hardware such as the CPU, memory, storage, and network devices.

A complete Linux operating system combines the Linux kernel with GNU tools, libraries, utilities, package managers, and desktop environments (optional).

Examples include:

- Ubuntu
- Debian
- Fedora
- Red Hat Enterprise Linux (RHEL)
- Rocky Linux
- AlmaLinux
- Arch Linux
- openSUSE

---

# 📌 What is an Operating System?

An **Operating System (OS)** is system software that acts as an interface between users, applications, and computer hardware.

It is responsible for:

- Process Management
- Memory Management
- File Management
- Device Management
- Security
- Networking
- User Management

Without an operating system, applications cannot communicate with hardware.

---

# 📌 History of Linux

In 1991, **Linus Torvalds**, a computer science student at the University of Helsinki, started building a Unix-like kernel as a personal project.

He released the source code publicly, allowing developers worldwide to contribute.

Over time, Linux became one of the most successful open source projects and is now maintained by thousands of contributors across the globe.

Today, Linux powers everything from smartphones to cloud data centers.

---

# 📌 Linux vs Unix

| Linux | Unix |
|--------|------|
| Open Source | Mostly Proprietary |
| Free to use | Commercial licensing in many distributions |
| Developed by the open-source community | Originally developed at Bell Labs |
| Highly customizable | Vendor-specific implementations |
| Widely used in Cloud and DevOps | Common in legacy enterprise systems |

Linux is inspired by Unix but is **not** Unix.

# 💼 Interview Questions

### **1. What is Linux?**

Linux is a free, open source, Unix like operating system kernel that manages hardware resources and provides the foundation for a complete operating system.

---

### **2. Who created Linux?**

Linux was created by **Linus Torvalds** in **1991**.

---

### **3. Why is Linux widely used in DevOps?**

Linux is stable, secure, lightweight, automation friendly, and is the preferred operating system for most cloud servers, containers, and Kubernetes environments.

---

### **4. Is Linux an operating system or a kernel?**

Technically, Linux is a **kernel**. A complete operating system is created by combining the Linux kernel with GNU tools, libraries, package managers, and other software.
